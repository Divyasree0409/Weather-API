# 🌦️ Weather App using API

A simple Weather Application that fetches real-time weather data using a Weather API and displays it in a user-friendly interface.

---

## 📌 Features
-  Search weather by city name
-  Displays temperature
-  Shows weather condition (Cloudy, Rainy, Sunny)
-  Humidity and wind speed
-  Real-time data using API
-  Responsive design

---

## Technologies Used
- HTML5
- CSS3
- JavaScript
- API Integration

---

## API Used
This project uses the **OpenWeather API** to fetch weather data.
